# 🎮 Tic Tac Toe Game
A simple and fun **Tic Tac Toe** game built using **HTML, CSS, and JavaScript**. This is a beginner-friendly project that allows two players to play against each other on the same device.
---
## ✨ Features
- 🎲 Two-player mode
- ✅ Real-time game status update
- 🏁 Win and draw detection
- 🔁 Restart game functionality
- 🎨 Clean and responsive UI
---
## 🛠️ Tech Stack
- **HTML** – structure
- **CSS** – styling
- **JavaScript** – game logic
